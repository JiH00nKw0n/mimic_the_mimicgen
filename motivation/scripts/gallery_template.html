MimicGen · 합성 데이터 감사

어떤 source 데모는 좋은 합성 데이터를 만들고, 어떤 건 아니다

MimicGen은 사람 source 데모 10개를 새 초기조건으로 transform해서 합성 데이터를 만들고, 성공한 것만 남긴다. 그런데 소스마다 전이 신뢰도(생성 성공률 = DGR)가 천차만별이다 — 어떤 소스는 어떤 배치로 옮겨도 잘 성공하고(고DGR), 어떤 소스는 거의 실패한다(저DGR).

각 태스크에서 많이 쓰인 소스(고DGR)와 적게 쓰인 소스(저DGR)의 실제 합성 데모를 성공·실패 × 가까운/먼 변형으로 나란히 놨다. 고DGR 소스는 거리와 무관하게 깔끔히 성공하고, 저DGR 소스는 대부분 실패하며 드문 성공도 아슬아슬하다. 이것이 소스를 균등하게 섞는 큐레이션(ancestry)이 해로운 이유이자, 필터가 고DGR 소스를 과대표집하는 편향이 오히려 이로운 이유다.

고DGR 저DGR 성공 실패 d = transform 거리(0=원본, 클수록 멀리 이동)
